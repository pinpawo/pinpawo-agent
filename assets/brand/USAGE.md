# PinPawo 主标使用规范

用户已选定本包中的紧凑爪印结构与 PinPawo 字标。黑白是当前暂用配色，后续仍可确认彩色版本。本包只包含这一套选定资产。

## 基本用法

- 名称写作 **PinPawo**，两个 P 大写，其余字母小写；使用随附组合版，不重新排字。
- 浅底使用纯黑 **#000000**；深底使用纯白 **#FFFFFF**。SVG 与 PNG 均为透明底。
- 单独标志 SVG 的设计框为 **12×12**；PNG 为 **512×512**。
- 组合版设计框为 **383×96**；PNG 为 **1532×384**。使用时保持原宽高比及内部间距。

## 尺寸与留白

- 单独标志最小设计框宽度为 **24 CSS px**；常规界面建议 **32 CSS px** 或以上。已检查 16、24、32 px，16 px 趾垫与留白过细，因此本规范采用 24 px 下限。
- 组合版最小宽度为 **128 CSS px**，等比高度约 **32 px**；此尺寸已在浅底和深底实际检查。以上数值以 100% 显示尺寸计，不是导出位图的总像素数。
- 四周安全留白至少为 **爪印设计框宽度 W 的 1/6**，即一个趾垫宽度。组合版以其中爪印的设计框宽度计算，不用整个组合的宽度。
- 例如：24 px 标志四周至少留 4 px；32 px 标志至少留 5.4 px，可向上取 6 px。SVG 内部已有空隙不代替外部安全留白。
- 优先使用 SVG；位图按显示尺寸的 2 倍或更高导出，保持等比缩放。

## 保持资产一致

不得拉伸、压扁、裁切图形，或改变趾垫大小、趾掌间距、掌垫形状、字形、字距及标志与字标的间距。不要用字体、Emoji 或系统符号替代本包路径。

字标使用 Noto Sans Regular 并已转为路径，无需安装字体；SIL OFL 1.1 许可证附在本包中。SVG 标题与说明已更新为正式主标，图形及字标路径与用户选定稿完全一致；PNG 与选定稿逐字节一致。

## 仓库中的源文件

`pinpawo-primary-black.svg` 是爪印几何的权威源。README 使用黑白组合版；TUI 欢迎页的字符图案从权威 SVG 生成。

修改源文件后运行 `npm run brand:generate -w @pinpawo/tui`；用 `npm run brand:check -w @pinpawo/tui` 检查字符图案是否漂移。其他应用图标不在本次范围内。
