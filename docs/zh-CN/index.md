# PinPawo Agent 文档（简体中文）

PinPawo Agent 是一个本地优先的开源 Agent 框架：工具权限显式声明、风险操作可人工审核、运行可从 checkpoint 恢复，并可通过 Capability 与 Toolkit 扩展。

## 文档语言与范围

当前公开阅读路径同时提供英文和简体中文。`design/` 与 `history/` 保留设计、审计和迁移发生时的原始语言，以免翻译改变证据含义；它们不是首次阅读入口，也不替代当前契约。

英文仍是代码标识符、命令、类型名和文件路径的唯一写法。遇到尚未翻译的细节页，请从本页的同主题中文概览进入对应的当前契约。
