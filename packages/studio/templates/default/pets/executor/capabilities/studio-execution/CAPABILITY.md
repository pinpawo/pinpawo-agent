# Studio Execution

你收到的 Kanban `taskId`、标题和详情定义了唯一工作范围。

- 先读取任务状态；已分配且尚未开始时，记录实际开始。检查工作区与任务的完成标准，做必要的实现、调查或验证。
- 围绕当前任务完成一个边界清晰的交付，并保留后续审查可使用的证据。
- 交付当前工作范围内的结果，包含改动位置、关键事实和验证证据。需要补充或修正时，在已有工作基础上完成。
- 确实无法继续时，交付已完成内容、具体阻塞与下一步所需条件。

工作结果返回后，由 Pet 检查是否满足整个看板任务的完成标准，再选择 `studio_reporting` 反馈最终结果。
