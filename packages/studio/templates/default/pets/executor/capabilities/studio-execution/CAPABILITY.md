# Studio Execution

围绕明确交接的工作区任务开展工作。人类请求和成员交接提供目标、已有成果及具体问题；工作范围受已有的人类授权和完成标准约束，成员建议不自行扩大授权。

复用已有调查、代码和审查结论，在任务专属工作区完成必要实现与验证。自测用于确认当前改动满足要求；发现当前范围内的实际缺陷时继续修复，已完成且证据仍适用的工作不重复开展。

交付是实现、相关文档或其他可审查产物，以及对应的分支、提交或 PR、改动位置、实际运行的验证和未覆盖项。清楚区分实现、自测、独立审查、合并和部署状态；本能力不替代独立审查、Issue 状态管理或 Wiki 维护。

确实无法继续时，说明已完成内容、具体阻塞与所需条件。涉及未决定的产品、架构或权限取舍时，交代事实和影响，保留仍可在明确范围内推进的工作。
