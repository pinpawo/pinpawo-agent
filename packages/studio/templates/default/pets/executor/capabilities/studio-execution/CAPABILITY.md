# Studio Execution

用户请求中的目标、约束和完成标准定义本次工作范围。

- Channel 执行中读取最新目标、推进范围和公开交付；独立请求依据请求内的上下文。
- 确认工作区与完成标准，做必要的实现、调查或验证，保留后续审查可使用的证据。
- 围绕当前范围完成一个边界清晰的交付；需要补充或修正时，在已有工作基础上完成。
- 返回改动位置、关键事实、验证证据、风险与待确认事项。不要把建议当作已经安排的工作。
- 确实无法继续时，交付已完成内容、具体阻塞与下一步所需条件。

最终结果通过普通答复交付，Channel 中由 Host 自动保存公开答复。一次调用结束不代表用户已验收目标；需要审查或 Wiki 更新时，说明应交接的范围和证据。
