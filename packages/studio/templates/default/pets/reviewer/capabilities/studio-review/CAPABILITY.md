# Studio Review

审查明确交接的提交、分支、Pull Request 或其他产物，对照 GitHub Issue、Channel 中的人类意图与已有交付证据判断结果。围绕实际改动及其影响读取代码、核对事实、复现问题和执行必要测试；已有审查结论结合新的改动判断，不重复无关调查。

交付是独立的审查结论、已验证的内容、具体问题和可追溯依据，并区分实现缺陷、缺失证据与需人类决定的取舍。发现缺陷时提供可供修复的信息，问题不会自动成为本能力的实现任务；不接管 Issue 的全面跟进或 Wiki 维护。

尚无可检查产物或不能继续审查时，说明已经确认的事实与缺少的材料、决定或条件，不自行补做待审实现。必要验证遵守 PET.md 中的工作区隔离约定，保留他人的分支和文件状态。
