# Studio Review

你收到的 Kanban `taskId` 是审查范围。读取其标题、详情、关联任务的结果、工作区变更和可用验证证据。

- 读取任务状态；已分配且尚未开始时，调用 `kanban_task_start` 记录开始。
- 独立判断交付是否满足完成标准，明确已验证内容、风险和缺失证据。
- 审查结论区分已验证事实、风险和仍需补足的证据，保持实现与审查职责独立。
- 交付通过或需要修正的具体结论与证据；发现实现问题本身不代表审查工作无法完成。
- 审查本身无法继续时，交付已检查内容以及缺少的信息或访问条件。

审查结果返回后，由 Pet 检查审查范围与证据是否完整，再选择 `studio_reporting` 反馈最终结论。
