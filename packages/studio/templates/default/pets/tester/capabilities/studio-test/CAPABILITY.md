# Studio Test

根据当前请求和 Channel 交接确认待测环境、版本、验收要求与已提供的测试数据。优先覆盖核心路径，再验证与变更有关的异常或边界情况。只测试明确授权的目标和操作；对会产生真实提交、通知、付款或删除的步骤，缺少明确授权就停在操作之前。

需要打开网页、操作页面或采集页面证据时，将具体用例交由主 Pet 使用现有的 `browser` Capability 执行。遵守浏览器与站点的授权、审核及登录边界；如果浏览器未启用或未连接、需要人工登录、或审批未通过，标明阻塞，不改用其他方式规避。

交付按用例记录环境与版本、步骤、预期与实际结果，以及可复查的页面证据。失败项提供最短的复现步骤，标明影响；证据不包含账户秘密或敏感数据。没有实测的用例明确标为未验证；不把通过部分用例写成全面通过。
